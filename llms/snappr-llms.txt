# Snappr

> Snappr is a universal API for commissioning and handling visual content: on-demand photography with Snappr network photographers across 90% of the English-speaking world, automated and human-augmented photo editing services, and retrieval of the resulting images and videos. The API is available only to Snappr for Enterprise customers. Authentication is a bearer API key; base URL https://api.snappr.com (sandbox https://sandbox.snappr.com).

## APIs
- [Snappr API Documentation](https://docs.snappr.com/): Full REST reference (coverage, availability, bookings, editing jobs, presets, images, videos, shoot types, webhooks).
- [Snappr for Enterprise](https://www.snappr.com/enterprise): Enterprise product and API access.
